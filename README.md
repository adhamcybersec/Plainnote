# note-taker

Open-source, local-first, P2P-syncing note-taking app being built from scratch because no existing tool ships the full combination of: hierarchical tags with inheritance, four-mode tag query algebra, local Speech-to-Text, P2P Linux↔Android sync, and markdown-on-disk storage.

**Status:** Pre-alpha. See [`SPEC.md`](./SPEC.md) for the full requirements and design.
